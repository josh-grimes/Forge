FORGE WORKOUT TRACKER

Open index.html in a browser. Keep index.html, style.css, script.js and forge-logo.png together in this folder.

Add a name, date and planned exercises, then Save Workout to save a plan. Each saved workout card shows its plan. Click Edit Workout to change the saved name, original date or planned exercises. For completed dates, you can also change the saved workout time in minutes:seconds (01:30 means one minute and thirty seconds). Click Save Changes to keep edits; Cancel Edit discards the editor changes. Existing calendar dates and completed results remain. Changing the original date moves its uncompleted calendar occurrence; a completed original occurrence remains on its historical date. Prior results retain their original exercise names if the plan changes.

Start a new workout with the header button. Start a saved workout from its card, its Review section, or its calendar detail card. During tracking, enter the actual set count and reps, weight and/or time for each set when the planned exercise included those values. The main workout timer starts automatically and cannot be changed during a running workout. The separate Stopwatch has Start, Stop and Reset controls and displays milliseconds. It resets at the end of each session and is never saved. Finish Workout stops the main timer and saves the results of a saved workout. For a new workout, click Save Workout afterward.

A completed calendar workout can have actual results and its workout time entered or edited manually through Record Results or Edit Results. The manual results form does not run either timer and also offers Set Time for editing a completed workout’s time. Recorded results and workout time appear in the calendar detail card and Review.

Drag a saved workout onto multiple calendar dates. Drag a calendar entry to another day to copy it. Completed entries are green, incomplete past dates are red, and today or future incomplete dates are orange. Drag the Rest Day tile onto a date, or select a date and press Add Rest Day. Rest days store only their dates, with no exercise or timer data. Remove a rest day using × on its calendar tile. Current streak counts consecutive completed workout or rest days ending today or yesterday; Best streak is the longest run so far. A date with both a workout and a rest day counts once. Future dates do not increase streaks before they arrive.

Workouts and rest dates are stored in this browser's localStorage for this page. They do not automatically sync between browsers or devices. Clearing browser site data may remove them.

Forge also supports previous set results, exercise progress charts, and weekly repeats from the Review controls on saved workouts.

NEW WORKOUT SECTIONS & SCHEDULING
Create and rename sections such as Warm Up, Main Workout, and Cool Down in New Workout. Assign each exercise to a section. Advanced Scheduling sets weekdays and optional start/end dates before the workout is saved. Existing workouts without sections appear under Main Workout.
